# EduMix 前端

基于 Vue 3、Vite、Vue Router 和 Axios 的混合式教学资源平台前端。

## 启动

```bash
npm install
npm run dev
```

开发地址默认为 `http://localhost:5173`，`/api` 请求会代理至 `http://localhost:8080`。

## 已实现页面

- 公共首页、公开内容搜索、登录与教师注册
- 教师工作台、课程与知识点管理
- 教学资源库、教学案例库、个人案例草稿
- AI 推荐与教学案例对话整合
- 个人收藏、积分中心、消息与私信
- 个人主页、资料编辑和教师主页
- 资源与案例审核、管理员账号和积分管理

接口封装位于 `src/api`，登录令牌由 Axios 请求拦截器统一携带。完整的环境配置、数据库初始化、测试账号和启动方法见项目根目录 [README](../README.md)。
